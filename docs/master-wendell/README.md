# Master's dissertation (Wendell Silva Soares, UFAL, 2016)

Sources for *Aplicabilidade e Desempenho do Global Media Transmission
Protocol (GMTP)* are in `dissertacao/tex/`.

The compiled PDF is not versioned (`*.pdf` is listed in `.gitignore`).
Historical references in this repository point to:

`docs/master-wendell/dissertacao/dissertacao-wendell-final.pdf`

The Mac working copy that supplied these TeX sources did not include
that PDF. Keep a local copy next to the TeX if you need to read the
formatted dissertation. The PowerPoint slides that accompanied the
defense (`Apresentação mestrado.pptx` and a related deck, together
about 6 MB) are also left out of git because of their size.

Figure assets referenced by the TeX may be incomplete in this snapshot.
Recover them from the author's working copy if a rebuild is needed. Do
not compile this dissertation as part of ordinary GMTP development.
