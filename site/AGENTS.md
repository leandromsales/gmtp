# GMTP project page

`site/` is a static snapshot of the public GMTP page, exported from Microsoft Word in May 2014. The page title is "Global Media Transmission Protocol (GMTP)".

| Path | Contents |
| --- | --- |
| `index.htm` | The page. Word HTML, with VML and Office namespaces. Author metadata names Leandro Melo de Sales. |
| `index_files/` | Images, styles, and the Word file list referenced by `index.htm` |

Edit `index.htm` and `index_files/` together. Relative links use `index_files/`. New visible text is English. Keep the existing page intact when the task is only to read or quote it.

This folder is the project page, not the protocol. Implementation lives in `linux/` and `app/`.
